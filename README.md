# Helm charts

This repository is primarily focused on the universal Helm chart located at
[`charts/appchart`](charts/appchart). It provides reusable building blocks for
describing and deploying applications on Kubernetes.

The repository can also contain and publish arbitrary standalone Helm charts
that are not part of `appchart`.

`appchart` and its libraries are a fork of
[`nixys/nxs-universal-chart`](https://github.com/nixys/nxs-universal-chart).
